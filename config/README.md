# Configuraciones

Esta carpeta almacenará configuraciones reproducibles y ejemplos sin secretos:

- Docker Compose utilizado en la VM.
- Configuración de Nginx.
- Unidades de servicio si corresponden.
- Reglas documentadas de firewall.
- Archivos `.env.example` exclusivamente con valores ficticios.

Nunca guardar archivos `.env`, claves privadas, tokens ni credenciales reales.
