HITO 4 - F4-E03: SESIÓN Y SECRETOS
Fecha: 2026-09-16

Búsqueda del mecanismo de sesión:
grep -RInE 'localStorage|sessionStorage|document\.cookie|cookies\(' frontend/src

Resultado:
frontend/src/lib/api.ts y frontend/src/lib/auth-context.tsx utilizan
localStorage con la clave jeroky_token.

Interpretación:
El token no se maneja como cookie. Persiste en el navegador y es accesible
desde JavaScript, por lo que existe un riesgo residual ante XSS.

Verificación de secretos:
git -C backend check-ignore -v .env
git -C frontend check-ignore -v .env.local
git -C backend ls-files .env
git -C frontend ls-files .env.local

Resultado:
.env y .env.local coinciden con las reglas .gitignore; ls-files no devolvió
ninguno de esos archivos. No se versionaron credenciales reales.
